# 标签 PDF 样例

Last updated: 2026-11-11

把 demo/testbed 出标下载的 PDF **放进本目录**（文件名建议）：

| 文件名 | 说明 |
|--------|------|
| `label-A6-1pp-parcel-post.pdf` | A6，Parcel Post |
| `label-A4-4pp-parcel-post.pdf` | A4-4pp，Parcel Post |
| `label-A6-1pp-express-post.pdf` | （可选）Express |
| `label-own-packaging-BE1P10.pdf` | （可选）OWN |

最少：**A6 + A4-4pp 各一份**即可交 Sign Off。

勿提交含真实收件人隐私的生产标签到公开仓；demo 假地址即可。若仓库策略不允许二进制，改用邮件附件并在 Sign Off 邮件中注明「PDF 另附」。
