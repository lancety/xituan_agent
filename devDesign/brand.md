# 全端 · 喜团商标基调色

Last updated: 2026-11-15

继承：[`00-platform-wide.md`](./00-platform-wide.md)  
商标参考：字标（青+黄打蛋器）· 圆形角色标（青环 + 黄围裙/麦穗 + 紫花序 + 棕线稿）

> **色值以商标取样为合同起点**；各端 token 映射可微调亮度/对比，**不得**换成另一套主色（如 GitHub 蓝顶替主青）。

## 基调色（Brand）

| 角色 | 名称 | 参考 hex（取样） | UI 用途 |
|------|------|------------------|---------|
| **主·装饰** | 青 Cyan | `#18C0C8` | 字标同色、描边、氛围 wash、logo 环 |
| **主·可交互** | 青 Primary / Fill | Light `#18C0C8`（字标同色） | 链接、选中、实心 CTA（商家入驻等）、`--color-primary`；暗色再降饱和见下表 |
| **副** | 黄 Yellow | `#E0B818` / 标内暖黄约 `#F8C058` | 次强调、促销/打蛋器点缀、谨慎高亮（勿大面积刷屏） |
| **副** | 紫 Purple | `#9878D0` | 次强调、点缀、与青区分的第二强调（勿做成「AI 紫渐变皮肤」） |
| **辅** | 棕 Brown | `#984838` 级 | 插画/线稿气质、极少用于大面积控件底 |
| **辅** | 黑 / 白 | `#000000` / `#FFFFFF` | 对比、反色字、logo 底；**暗色界面底用分层蓝灰，忌大面积纯黑糊成一片** |

主青在 light / dark 都要有 **hover / active** 变体，并保证按钮上文字对比（`--text-on-primary`）。

## 暗色微调（强制）

商标取样 `#18C0C8` 是 **light / 字标** 合同色。暗色蓝灰底上若直接大面积铺原样主青，会显霓虹、刺眼——**必须降饱和 / 略降亮度**，仍可读作「同一主青家族」，不得换成蓝或其他主色。

| Token 角色 | Light（Site） | Dark（Site） | 用途 |
|------------|---------------|--------------|------|
| 装饰 / primary | `#18C0C8` | `#4AADB3` | 边、环、wash、选中「商户主页」等 |
| ink（浅底上的文字 / 链接） | `#0E7C83` | `#4AADB3` | `--xituan-brand-cyan-ink` / `--fgColor-link` / `--info-text`；仅文字 |
| 实心 fill CTA | `#18C0C8` | `#197A80` | 顶栏「商家入驻」、小程序 tile、`.site-btn-primary` |
| hover | `#14A8B0` | ink `#5BBCC2` / fill `#1F8A90` | 悬停 |

**硬约束：** 亮色 chrome（商家入驻 / 小程序 / 选中导航等）的**填充与装饰**必须用字标青族，**禁止**套用暗色那套加深青绿（如 `#0A7F86` / `#197A80`）当亮色填充。  
**例外（2026-11 购物车 critique 定稿）：** 亮色**正文文字 / 链接**用 ink `#0E7C83`——`#18C0C8` 作文字在白/浅灰底上仅 ~2:1，不达 WCAG AA；ink 只用于文字，不用于底色、描边、装饰。

实现：`xituan_site` → `theme.css` 的 `--xituan-brand-cyan*` / `--xituan-brand-cyan-ink` / `--xituan-brand-cyan-fill*`（亮暗成对）。  
`--color-primary*`：**Light → 字标青**；**Dark → ink**（深底上可读；实心钮走 fill）。  
字标 PNG 暗色可另用轻微 `saturate/brightness`（Site `.site-logo-img`）或暗色专用资产，避免原样高饱和青贴在蓝灰底上。

## 订单 / 活动模式主题色（全端硬合同）

在商标基调之上，按经营模式固定**色相**。亮色 Primary 与微信小程序对齐（`xituan_wechat_app/utils/theme-mode.util.ts`）；Site / App / CMS 必须套用，不得把团购画成黄、预定画成紫等。

| 模式 | 订单模式 | 色调 | Light Primary（合同锚） | Dark Primary（降饱和，非霓虹） | Light 文本区 tint | Soft badge |
|------|----------|------|-------------------------|--------------------------------|-------------------|------------|
| **零售** | `REGULAR` | 紫 | `#8B5CF6` | `#A78BFA` / hover `#8B5CF6` | `#F5F3FF` 级 | `purple` |
| **团购** | `OFFER` | 青 | `#06B6D4` | `#2A9FAD` / hover `#238A96` | `#F0F9FF` 级 | `cyan` |
| **预定** | `PREORDER` | 橙黄 Amber | `#F59E0B` | `#C98512` / hover `#A86E0E` | `#FFFBEB` 级 | `amber` |

**可读性派生 token（Site `theme.css`，亮暗成对）**

锚点色作白字实心底或浅底文字时对比度不足，派生两档：

| 模式 | `--mode-*-fill`（白字实心 CTA） Light / Dark | `--mode-*-ink`（浅底 / tint 上文字） Light / Dark |
|------|------|------|
| 零售 | `#7C3AED` / `#7C3AED` | `#6D28D9` / `#B9A4FC` |
| 团购 | `#0891B2` / `#1E7F8A` | `#0E7490` / `#4FBAC6` |
| 预定 | `#D97706` / `#A86E0E` | `#B45309` / `#E0A23A` |

- 实心 CTA（购物车结算等）用 fill，白字须 **≥18px 粗体**（团购/预定亮色 fill 白字约 3.2–3.7:1，只满足大字门槛）。  
- 选中标签 / 链接用 tint 底（`--mode-*-bg`）+ ink 字，不用白字压锚点色。  
- 锚点色（`--mode-*`）继续用于色点、色条、描边、shadow 等装饰。

**暗色硬约束（与品牌青同理）**

- 暗色**禁止**直接铺亮色锚点或高饱和浅色（如 `#22D3EE`、`#FBBF24`、`#10B981`）作大面积实心 CTA / 面板状态 pill——炭底上会刺眼。  
- 暗色可沿用同色相，但须 **降饱和 / 略降亮度**；结算钮、面板强调字、加购钮走 Dark Primary 表。  
- 活动详情面板状态 pill（如「进行中」）：Light 可用鲜明绿/琥珀；Dark 用深绿/深琥珀实心（例 active `#047857`，published `#B45309`），勿用霓虹绿。  
- 列表卡图上角标：Dark soft badge 默认近透明 → 叠白图看不清；图上角标须用不透明 chip（可覆盖 `--badge-state-bg`）。

**套用范围（凡属该模式的界面元素）**

- 活动/订单页顶栏、主 CTA（含详情结算钮）、进度/剩余天数等强调字  
- 列表卡文本区 tint（`--card-*-info-bg`，亮淡 wash / 暗低饱和混入 block）；首页发现轨标题色条  
- 加购按钮、shadow；订单详情头 tint（`--order-header-*` / `--order-accent-*`）  
- **勿**再用卡顶/文本顶「色条」代替 tint（已弃用）

**与商标基调的关系**

- 平台级 CTA / 链接仍走商标主青（字标族）；**进入零售/团购/预定业务壳后**，壳内强调色切换为上表模式色。  
- 团购青（`#06B6D4`）与商标字标青（`#18C0C8`）同属青系但**角色不同**：前者是活动模式主题，后者是品牌主色；勿混为一谈、也勿互相替换。  
- 预定 Amber 与商标副黄（`#E0B818`）同属暖色，预定业务优先用 Amber 合同色。

Site 已落地：`--mode-retail|offer|preorder`（及 hover/light/bg/shadow）、`--card-*-info-bg`、`--order-accent-*`（`xituan_site/src/styles/theme.css`）。

## Badge / 状态色谱（功能色）

与基调色并存；详规 [`badge.md`](./badge.md)。语义上须覆盖：

**红 · 橙 · 黄 · 绿 · 青 · 蓝 · 紫 · 黑 · 白 · 灰**

- 状态 soft：`positive` / `caution` / `danger` / `neutral` / `muted`（+ 需要时 info）  
- 按钮 filled：`red` / `orange` / … / `cyan` / `blue` / `purple` / `default`  
- 青/紫可与品牌青紫对齐，但 **订单态 / 活动模式颜色语义优先于装饰**

## 亮 / 暗如何「用上」基调（合同）

| 主题 | 必须看得见品牌 | 禁止 |
|------|----------------|------|
| **Light** | 主按钮/链接/关键选中用主青；副黄紫作克制点缀；灰阶表面仍分层清晰，整体有「一套色」而不像默认 Ant/GitHub 蓝灰皮肤 | 只有灰阶 + 偶然蓝链；或到处点缀无主次 |
| **Dark** | 主青与三模式色仍出现在主 CTA、链接、选中态，但用 **暗色微调表**（勿原样 `#18C0C8` / `#FBBF24` 等霓虹大面积铺底）；可用低饱和 tint | 原样高饱和刺眼霓虹；整页无品牌色；或纯黑底 + 灰字 |

## 现状债（验收时对照）

| 问题 | 说明 |
|------|------|
| Site 主色 | **已收敛**（2026-11）：亮色字标青；暗色 ink/fill；勿再写回 `#0969da`；亮色勿套暗色加深青绿 |
| CMS / 微信 / App | 仍可能偏中性蓝灰；对齐同一 strong/ink 拆分后再扫主路径按钮 |

收敛方向：各端 `color-primary` **亮色对齐字标青、暗色对齐 ink/fill**；三模式色相固定、暗色降饱和；副黄紫进 token；亮暗成对。

## Agent

改主题色：先读本文 + 对应 `*-theme.md`；改 badge：再读 [`badge.md`](./badge.md)。  
改零售/团购/预定相关 UI：必须套用本文「订单 / 活动模式主题色」；亮色锚点对照微信 `theme-mode.util.ts`，暗色对照本文 Dark 表（勿抄亮色霓虹值）。  
勿引入第二套「流行紫渐变」品牌；勿打乱三模式色相映射。
