# 报税 BS 手动字段 / Director loan 结转 / P&L 工资行

日期：2026-11-01

## 1. BS 系统预设 / 手动保留

- **银行存款**：读该财年 AUD 银行 ledger processed CSV，取 `occurredAt ≤ 财年末` 且有 `balance` 的最近一笔（多块按日期取最新，单账户启发式）。每次重新生成刷新。
- **固定资产净值（PPE）**：财年末仍持有设备；优先该年折旧 `closingValue`，否则 `equipmentBookValueCalculationUtil`；处置日 ≤ 财年末不计。每次重新生成刷新。
- **其他资产 / 其他负债**：默认 `0`；用 overview `gst.netGst` 种子——`>0` → 其他负债（应付 GST），`<0` → 其他资产（应收 GST）。同年已保存的手改优先保留。
- **股本**：同年已填保留；否则从上一年 BS `shareCapital` 结转。
- **留存收益期初**：上年期末 RE（期初 + 上年本年利润）。
- **本年利润**：后端按与 CMS P&L 相同口径（订单净+发票净 − 日常六类 − 罚款 − 折旧 − 工资 − super）写入；CMS 仍可用 `pnlManual` 覆盖后同步到 BS。
- **应付公积金**：仍手填（无法可靠区分已付/未付）。
- 前端切换财年若目标年无报表，清空本地 `balanceSheetData`，避免串显示别年数值。

## 2. 上年 Loan to / from director 结转

- 对**同一董事/股东**：期末先把 loan to 与 loan from **轧差**——大的一边减小的一边，小的一边归 0，**只把净额**作为下年期初一行，再加本年发生额。
- 两边原值都往下滚会使明细逐年膨胀；轧差后结转才是常规小公司管理账/报税展示做法（与 CMS 表内合计净额逻辑一致）。
- 实现：`priorClosingNetDirectorLoans` 优先用上一年年 items 合计再轧差（无 items 用 total）；**两侧都插入** `Opening balance (YYYY-YY)`（净额侧为余额，归零侧为 `$0`，避免用户以为漏结转）。

## 3. P&L「董事工资 / 员工工资 / 两人工资合计 / 养老金」

- 金额来自支出汇总 `salary` / `superannuation`（系统数据）。
- 「董事 / 员工」两行曾是前端 **`wages / 2` 硬拆**，不是两笔真实支出；`两人工资合计` 只是合计行；养老金文案偏 24-25 双人工资场景说明。
- 已改为单行「工资」= 支出类型合计，去掉 50/50 硬编码。若以后要分董事/员工，需支出侧可区分字段或备注规则，不能再除以 2。
